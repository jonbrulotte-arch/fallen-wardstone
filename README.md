# Fallen Wardstone

A compact, complete 2D browser RPG built with Phaser, TypeScript, and Vite.

## Run

Install dependencies, then start the dev server:

```powershell
npm install
npm run dev
```

Build for production:

```powershell
npm run build
```

## Controls

- Move: `WASD` or arrow keys
- Interact: `E` or `Space`
- Menu: `M` or `Esc`
- Battle commands: mouse or touch buttons

## Game Loop

Speak with Elder Rowan, recover the wardstone shard in Briarwild Road, enter Wardroot Shrine, defeat the Hollow Warden, and restore Stonefall Village.
